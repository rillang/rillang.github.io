Roadmap

Where Rill stands and where it is going. Nothing below "next" has a date; the order may change. Sources: the findings notes, the roadmap and the RFC index.

Done

  • done Self-hosted compiler emitting native arm64 Mach-O and ELF, with no external tools
  • done Bootstrapping from a checked-in Rill seed; the original Zig compiler is gone
  • done Conservative parallel garbage collector; green-thread scheduler on all cores
  • done Structured concurrency: group/spawn, channels, parMap, Mutex, Atomic
  • done SSA optimizer (inlining, mem2reg, simplification)
  • done Value semantics for arrays and maps; panic backtraces
  • done Generics and interfaces
  • done Pattern matching
  • done rill fmt, rill lsp, DWARF line tables, rill debug
  • done Directory modules and a standard library embedded in the compiler (std/strings, fs, os, json, time, …)
  • done Packages from Git: rill.mod, rill.sum, minimal version selection, pinned tags, signatures, vendoring; builds never fetch
  • done Warnings and enforced lints; rill api, rill release, rill fix

Next

  • next Updates and security: rill mod outdated, rill update (changelog, API diff, automatic migration, pull request), retractions, rill mod audit
  • next Incremental builds: per-module summaries, a content-addressed cache, parallel compilation along the module graph
  • next /// doc comments, rill doc and doctests
  • next Language rough edges: if let on results, ? in tests, annotated closure parameters, explicit type arguments

Planned

  • planned WebAssembly target (WASI, single-threaded first)
  • planned A playground in the browser, on top of the WebAssembly target
  • planned rill tour and exercises
  • planned A toolchain version manager in rill, and mise integration
  • planned std/net and std/http
  • idea Language: a character type and Unicode strings, error types, select and timeouts on channels, annotated closure parameters
  • idea Supervised tasks and actors in the standard library, a REPL
