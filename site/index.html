Code like Swift. Build like Go. Go as deep as Rust.

One language from scripts to engines: scripts, tools, web services, games and simulations. Rill grows with your program — a script needs nothing but print, an engine adds nogc code, arenas and SIMD — and it is built so that people and AI agents can work on the same code with confidence. One self-contained toolchain: no C compiler, assembler or linker anywhere.

Get started Read the book Rill by Example
taste.rl
enum Expr {
  case num(Int)
  case add(Expr, Expr)
  case mul(Expr, Expr)
}

fn eval(_ e: Expr) -> Int {
case .num(n): return n
case .add(a, b): return eval(a) + eval(b)
case .mul(a, b): return eval(a) * eval(b)
}

fn main() {
  let e: Expr = .add(.num(2), .mul(.num(3), .num(4)))
  let big = [1, 2, 3, 4].map { $ * 10 }.filter { $ > 15 }
  print("result ${eval(e)}, big ${big.len()}")
}

test "eval follows the tree" {
  expect(eval(.mul(.num(2), .num(5))) == 10)
}
$ rill run taste.rl
result 14, big 3

Why Rill

Grows with your program

A script needs nothing but print. A service adds types, packages and concurrency. An engine adds nogc code, arenas, SIMD and unsafe — each step opt-in, local and as readable as the rest planned.

Built for people and AI agents

One obvious way to write things, diagnostics with stable codes, one formatter, and migrations as code (rill fix): what makes code easy for an agent to write and review helps every reader.

One binary, whole toolchain

rill runs, builds, tests, formats, debugs and serves your editor (run, build, test, fmt, debug, lsp). Nothing else to install.

No C toolchain

The compiler emits arm64 machine code and writes signed Mach-O or static ELF files itself. Cross-compiling from macOS to Linux is a flag.

Self-hosting

About 19 000 lines of Rill compile themselves to a byte-identical fixpoint, starting from a checked-in seed, the way Go bootstraps from an earlier Go.

Structured concurrency

group { spawn { … } }, channels, parMap, Mutex and Atomic on all cores. Tasks never outlive their group; sharing a var between tasks is a compile error.

Pattern matching

One pattern language for switch, if case, guard case, let, for and functions made of cases, with exhaustiveness checks that name the missing case.

Value semantics

Structs, arrays and maps are values, copied lazily on write. No aliasing surprises, no ownership annotations; a garbage collector reclaims memory.

Fast to build

Hello world builds in about 0.2 s; the compiler rebuilds itself in about 2 s on an Apple M4. Measured numbers and context.

For humans and models

One obvious way to write things, explicit types at every function boundary, stable error codes and --json diagnostics, tests next to the code.

Concurrency you can read

A group waits for every task spawned inside it. Values captured by a task are copied into it, so tasks cannot race on them; channels, Mutex and Atomic are the ways to share. Tasks are green threads scheduled on all cores with work stealing and preemption.

Concurrency in the book

concurrency.rl
fn main() {
  let urls = ["/", "/docs", "/blog", "/about"]
  let sizes = Channel<Int>(capacity: 4)
  group {
    for u in urls {
      spawn { sizes.send(u.len() * 100) }
    }
  }
  sizes.close()
  var total = 0
  for s in sizes {
    total += s
  }
  let squares = [1, 2, 3, 4].parMap { $ * $ }
  print("total $total, squares ${squares[3]}")
}
$ rill run concurrency.rl
total 1700, squares 16

Patterns everywhere

Match arrays by shape, maps by key, enums by case and structs by field, with where guards. A switch without default must cover every value, and the compiler tells you which case is missing.

Pattern matching in the book

patterns.rl
fn describe(_ xs: [Int]) -> String {
  switch xs {
  case []: return "empty"
  case [x]: return "just $x"
  case [first, ...rest] where first > 100: return "big start, ${rest.len()} more"
  case [first, second, ...]: return "$first, $second, ..."
  }
}

fn port(_ conf: Map<String, Int>) -> String {
  switch conf {
  case ["port": p, "tls": 1]: return "https on $p"
  case ["port": p]: return "http on $p"
  default: return "no port"
  }
}

fn main() {
  print("${describe([])} | ${describe([7])} | ${describe([500, 1])} | ${describe([1, 2, 3])}")
  print("${port(["port": 443, "tls": 1])} | ${port(["port": 80])}")
}
$ rill run patterns.rl
empty | just 7 | big start, 1 more | 1, 2, ...
https on 443 | http on 80

Errors in the types

No exceptions and no null. T? may be missing, T! may fail; ? passes the problem up, ?? supplies a default. Panics are for bugs and stop the program.

Values, not references

Copying a struct copies its arrays too (lazily). Only inout parameters change a caller's variable, and the call site says so with &.

errors.rl
fn parsePort(_ s: String) -> Int! {
  guard let n = s.toInt() else {
    return fail("not a number: $s")
  }
  return n
}

fn config(_ raw: String) -> String! {
  let port = parsePort(raw)?
  return "listening on $port"
}

fn main() {
  print(config("8080") ?? "?")
  if case .err(e) = config("http") {
    print("error: ${e.msg}")
  }
}
$ rill run errors.rl
listening on 8080
error: not a number: http
values.rl
struct Team { name: String, members: [String] }

fn main() {
  var a = Team(name: "core", members: ["ana"])
  var b = a
  b.members.push("bo")
  print("${a.members.len()} ${b.members.len()}")
  a.name = "lang"
  print("${a.name} ${b.name}")
}
$ rill run values.rl
1 2
lang core

Honest status

  • Rill is experimental and has no releases yet; you build it from source.
  • It runs on arm64 only: macOS and Linux. No x86-64, no Windows (a WebAssembly target is planned).
  • There is no standard library or package manager yet: a handful of builtins cover files, processes and the environment. Both are next.
  • The language will still change in incompatible ways before 1.0.
