Get started

There are no releases yet: you build Rill from source. It takes one command and nothing but the repository.

Requirements

  • An arm64 computer running macOS (Apple silicon) or Linux.
  • Git, to get the source. No C compiler, linker, Python or package manager.

x86-64 and Windows are not supported.

Build

shell
git clone <repository> rill
cd rill
sh bootstrap.sh
export PATH="$PWD/out:$PATH"

bootstrap.sh builds the compiler with the checked-in seed (a previous Rill compiler), then with itself twice, checks that the last two builds are byte-identical, and runs the test suite. The compiler is out/rill.

Your first program

hello.rl
fn main() {
  let name = "Rill"
  print("Hello, $name!")
}
$ rill run hello.rl
Hello, Rill!
CommandWhat it does
rill run app.rl [args]compile and run
rill build app.rl -o appcompile to an executable
rill build app.rl --target=linux-arm64cross-compile (static ELF from a Mac, or the other way)
rill test app.rlrun the file's test blocks
rill fmt app.rlformat in place
rill debug app.rldebug in lldb with Rill's formatters
rill lsplanguage server for your editor

Editor

Any editor with an LSP client works: point it at rill lsp for *.rl files. Diagnostics, hover, go to definition, formatting and document symbols are supported. Helix (languages.toml):

languages.toml
[[language]]
name = "rill"
scope = "source.rill"
file-types = ["rl"]
language-servers = ["rill-lsp"]

[language-server.rill-lsp]
command = "rill"
args = ["lsp"]

Neovim: vim.lsp.start({ name = "rill", cmd = { "rill", "lsp" } }) in a FileType rl autocommand. More in the tooling chapter.

How fast is it?

Measured on an Apple M4 on 2026-11-02, single runs:

TaskTime
rill build hello.rl0.22 s (623 KB executable with runtime and debug info)
the compiler building itself: ~19 000 lines of Rill plus a 4 500-line runtime2.1 s

The optimizer is young and the garbage collector takes a large share of a self-compile; docs/perf.md keeps the history and the analysis. We have not benchmarked Rill against other languages.
