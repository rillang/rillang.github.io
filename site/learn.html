Learn Rill

Everything here runs with the compiler in the repository: every program in the book and in Rill by Example is checked against its expected output.

The Rill Book

The language from the ground up, in fourteen short chapters: from building the compiler to concurrency, memory and tooling, with a built-in reference and an honest list of what is missing.

Rill by Example

35 small runnable programs, one topic each, with their output. Good for a quick look at the syntax or a reminder.

Tutorials

Four small real programs built step by step: a wc clone, a parallel file hasher, a JSON config loader, and a library published as a package.

Error reference

Every compiler diagnostic has a stable code (E0001…) with a one-line example.

Specs and RFCs

The design documents behind each feature: generics, pattern matching, the GC and scheduler, the native backend, and the planned packages.
