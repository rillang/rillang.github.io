Roadmap

Code like Swift, build like Go, go as deep as Rust — where Rill stands and where it is going. Milestones have no dates; the order may change. Sources: the findings notes, the roadmap and the RFC index.

Done

  • done Self-hosted compiler emitting native arm64 Mach-O and ELF, with no external tools
  • done Bootstrapping from a checked-in Rill seed; the first bootstrap compiler is gone
  • done Conservative parallel garbage collector; green-thread scheduler on all cores
  • done Structured concurrency: group/spawn, channels, parMap, Mutex, Atomic
  • done SSA optimizer (inlining, mem2reg, simplification)
  • done Value semantics for arrays and maps; panic backtraces
  • done Generics and interfaces
  • done Pattern matching
  • done rill fmt, rill lsp, DWARF line tables, rill debug
  • done Directory modules and a standard library embedded in the compiler (std/strings, fs, os, json, time, …)
  • done Packages from Git: rill.mod, rill.sum, minimal version selection, pinned tags, signatures, vendoring; builds never fetch
  • done Package updates and security: rill mod outdated, rill update (changelog, API diff, --pr), retractions, rill mod audit with reachability
  • done Warnings and enforced lints; rill api, rill release, rill fix
  • done rill test on the level of go test: a test cache, benchmarks, coverage, fuzzing
  • done Profiling: std/pprof and rill pprof (CPU, heap and task profiles)
  • done Faster builds: parallel code generation and a parallel optimizer
  • done v0.2 Instant: a function cache and a build key (an unchanged build in 0.01 s), dead-function elimination, rill run keeps its binary (11 ms to start), #!/usr/bin/env rill scripts
  • done A smaller language, if let on results, if and switch values, top-level let

Milestones

  • next v0.3 Foundations — language for libraries
    Error types, Char and Unicode strings, byte arrays, explicit type arguments, struct equality, default field values and field visibility, UFCS across modules, test helpers with diffs. Showcase: A library published as a package and updated with rill update.
  • planned v0.4 Encode — data in and out
    Encoding derived by the compiler for every type; typed JSON, TOML and CSV; config structs from files, environment and flags; file embedding; time zones. Showcase: A CLI tool with a config file.
  • planned v0.5 Concurrency — the network runtime
    A netpoller and std/net, select, timers, one cancellation and deadline model, task groups. Showcase: A TCP chat server.
  • planned v0.6 Crypto — security in Rill
    Hashes, HMAC, AEADs, signatures, X.509 and TLS 1.3, written in Rill; password hashing, UUIDs. Showcase: An HTTPS request without system libraries.
  • planned v0.7 Web — HTTP
    std/http: HTTP/1.1 and HTTP/2 server and client, router, middleware, typed handlers; logging, compression, rill watch. Showcase: A static file server and reverse proxy.
  • planned v0.8 API — web APIs
    OpenAPI and a docs page generated from the handlers, problem details, validation, JWT, WebSockets and server-sent events. Showcase: A web service with a JSON API.
  • planned v0.9 Data — databases
    std/sql, a native Postgres driver, SQL checked at build time against the migrations, rill db migrations, Decimal, database test fixtures. Showcase: A CRUD service on Postgres.
  • planned v0.10 Services — production services
    A Redis/Valkey client, a Postgres job queue, metrics, health checks and graceful shutdown. Showcase: The package proxy runs on Rill.
  • planned v0.11 x86-64 — servers
    An x86-64 backend for Linux (a spike already runs) and macOS, cross-compiling, container images. Showcase: The proxy on an x86-64 server.
  • planned v0.12 Beta DX — public beta
    rill doc, completion and code actions, a VS Code extension, rill new templates, better diagnostics, a package index, an installer, rill tour, a playground. Showcase: The public beta.
  • planned v0.13 FFI — native libraries
    A foreign function interface: C libraries, callbacks, rill bind; SQLite. Showcase: SQLite from Rill.
  • planned v0.14 Metal — as deep as Rust
    nogc functions, files and modules; arenas and pools; unsafe; SIMD; tasks the collector never stops (spawn nogc) and binaries without a collector (--nogc). Showcase: A simulation without GC pauses.
  • planned v0.15 Native apps — desktop and graphics
    window and gpu packages for desktop apps and 2D/3D rendering (Metal, Vulkan), a 2D engine. Showcase: A GPU triangle; a small game.
  • planned v0.16 Agent-native — the toolchain for agents
    --json for every command, rill mcp (an MCP server), structured test output. Showcase: An agent builds and migrates a project end to end.
  • planned v0.17 Everywhere — platforms
    Windows, WebAssembly and a browser playground. Showcase: The same program everywhere.
  • planned v0.18 Protocols — more protocols
    HTTP/3 and QUIC, gRPC, OpenTelemetry, YAML, message brokers, HTML templates, S3.
  • planned 1.0 — the promise
    A compatibility guarantee, signed reproducible releases. Not soon: the v0.x series comes first.

Not planned: ownership and lifetimes as in Rust (the escape check of nogc arenas is the deliberate alternative), macros, inheritance, a VM. The details: RFC 0008.
