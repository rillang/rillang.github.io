Roadmap

Code like Swift, build like Go, go as deep as Rust — where Rill stands and where it is going. Milestones have no dates; the order may change. Sources: the findings notes, the roadmap and the RFC index.

Done

  • done Self-hosted compiler emitting native arm64 Mach-O and ELF, with no external tools
  • done Bootstrapping from a checked-in Rill seed; the first bootstrap compiler is gone
  • done Conservative parallel garbage collector; green-thread scheduler on all cores
  • done Structured concurrency: group/spawn, channels, parMap, Mutex, Atomic
  • done SSA optimizer (inlining, mem2reg, simplification)
  • done Value semantics for arrays and maps; panic backtraces
  • done Generics and interfaces
  • done Pattern matching
  • done rill fmt, rill lsp, DWARF line tables, rill debug
  • done Directory modules and a standard library embedded in the compiler (std/strings, fs, os, json, time, …)
  • done Packages from Git: rill.mod, rill.sum, minimal version selection, pinned tags, signatures, vendoring; builds never fetch
  • done Warnings and enforced lints; rill api, rill release, rill fix

Milestones

  • next v0.2 Instant — speed and scripts
    Incremental builds, cached binaries for rill run, #!/usr/bin/env rill, fast start; package updates and security (rill update, rill mod outdated, rill mod audit). Showcase: Scripts replace shell and Python one-offs.
  • planned v0.3 Batteries — the standard library
    net/http (server and client), command-line flags, logging, regular expressions, crypto, encodings, time formats, test helpers with diffs; error types and Unicode strings. Showcase: A web service with a JSON API.
  • planned v0.4 Metal — as deep as Rust
    nogc functions, files and modules; arenas and pools; unsafe and C libraries; SIMD; tasks the collector never stops (spawn nogc) and binaries without a collector (--nogc). Showcase: A simulation or game loop without GC pauses.
  • planned v0.5 Agent-native — the toolchain for agents
    rill doc with doctests, --json for every command, rill mcp (an MCP server), completion, rename and code actions in the language server. Showcase: An agent builds and migrates a project end to end.
  • planned v0.6 Everywhere — platforms
    An x86-64 backend for Linux and macOS, WebAssembly and a browser playground, then Windows; cross-compiling between all of them. Showcase: The same program everywhere.
  • planned 1.0 — the promise
    A compatibility guarantee, signed reproducible releases, a toolchain version manager.

Not planned: ownership and lifetimes as in Rust (the escape check of nogc arenas is the deliberate alternative), macros, inheritance, a VM. The details: RFC 0008.
